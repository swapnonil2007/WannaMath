# wanna math (`WannaMath`)

An interactive 2D & 3D engineering mathematics visualization platform built to strengthen geometric intuition across **Multivariable Calculus**, **Coordinate Systems**, **Jacobians**, **Linear Algebra**, **Vector Calculus**, and **Fluid Dynamics**.

## v1.0 Core Curriculum (Multivariable Calculus)
1. **Double Integration (`/calculus/double-integrals`)** — 2D domains & 3D volume surfaces, Riemann prisms, Type I/II cross-sectional slicing, and Fubini's Theorem order change ($dy\,dx \leftrightarrow dx\,dy$).
2. **Triple Integration (`/calculus/triple-integrals`)** — 3D bounded solids, 1D ray $\rightarrow$ 2D curtain $\rightarrow$ 3D volume accumulation, 2D coordinate wall shadow projections, and all 6 orders of integration.
3. **Coordinate Systems (`/calculus/coordinate-systems`)** — Interactive 2D Cartesian/Polar and 3D Cartesian, Cylindrical $(r,\theta,z)$, and Spherical $(\rho,\phi,\theta)$ coordinate surfaces, local basis vectors, and differential volume elements ($dV$).
4. **Jacobians (`/calculus/jacobians`)** — Dual $(u,v) \leftrightarrow (x,y)$ grid morphing, local linear approximation & tangent parallelograms, 2D/3D Jacobian matrices, and change-of-variables integration.
